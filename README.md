# 英字変換 for Discord

全角・半角の英字を、大文字・小文字を保ったまま、Unicodeの数学用太字（U+1D400〜U+1D433）に変換するツールです。

**ChatGPT → 𝐂𝐡𝐚𝐭𝐆𝐏𝐓**  
**ＣｈａｔＧＰＴ → 𝐂𝐡𝐚𝐭𝐆𝐏𝐓**

[ブラウザで使う](https://moriyakeiichi.github.io/channel-name-converter-for-discord/) · [ソースコード](https://github.com/moriyakeiichi/channel-name-converter-for-discord)

## ローカルで使う

1. `index.html` をブラウザで開きます。通常はファイルのダブルクリックで開けます。
2. 左側の欄（狭い画面では上側）に文字を入力・貼り付けします。
3. 「結果をコピー」を押し、Discordなどに貼り付けます。

インストール、ログイン、ビルド、APIキーは不要です。HTMLファイル単体に必要な画面・処理が入っています。入力内容を外部に送信・保存する処理、外部ライブラリ、外部フォント、アクセス解析はありません。

ブラウザが自動コピーを許可しない場合は、結果が選択され、手動コピーの案内が表示されます。Macでは ⌘C、Windowsでは Ctrl+C でコピーしてください。

2026年10月19日の画面・コピー確認は、MacのChromeからローカルサーバーにアクセスする方法で実施しました。操作ツールの制限により、`file://` での直接表示・コピーは未確認です。詳細は [VERIFICATION.md](VERIFICATION.md) を参照してください。

## 変換の範囲

| 入力 | 出力 |
| --- | --- |
| A〜Z、Ａ〜Ｚ | 𝐀〜𝐙（U+1D400〜U+1D419） |
| a〜z、ａ〜ｚ | 𝐚〜𝐳（U+1D41A〜U+1D433） |
| それ以外の文字 | そのまま |

日本語・半角数字・全角数字・記号・絵文字・空白・改行は変換しません。アクセント付き英字など、上記4範囲に含まれない文字も変更しません。変換済みの数学用太字も、そのまま残します。

全体にNFKC正規化をかける方式は使っていません。数字や記号まで変わることを防ぐため、指定された英字だけを置き換えています。

## 利用時の注意

フォント変更ではなく、数学用の別の文字に置き換える仕組みです。アプリや端末によって、表示・検索・読み上げの扱いが異なることがあります。Discordでの保存と保存後の表示は、実際の利用環境で確認してください。Discordの公式ツールではありません。

文字を変換することと、Discordがその名前を受け付けることは別の確認です。チャンネル名を自動で変更する機能はありません。
